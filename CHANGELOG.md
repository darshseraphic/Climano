# Changelog

All notable user-facing changes to Climano are documented here.

## [1.1.2] - 2026-11-07

### Changed
- Updated light-theme weather cards, metric cards, forecast tiles, and status surfaces to a warm off-white (`#F7F2EB`).
- Preserved the white popup background and existing dark-theme card colors.


## [1.1.1] - 2026-11-07

### Changed
- Set the light-theme popup background to pure white (`#FFFFFF`).
- Set weather cards and status panels in the light theme to a soft neutral gray (`#F5F5F5`).
- Preserved the existing dark-theme palette and component behavior.

## [1.1.0] - 2026-11-07

### Changed
- Renamed the extension from Votrixain Weather to **Climano** throughout the user-facing extension interface and Chrome manifest.
- Replaced the previous sun brand mark with a monochrome cloud logo in the popup and extension icons.
- Updated the popup version label to 1.1.0.
- Reworked `design.md` to describe Climano's weather-focused visual system rather than the former link-cleaning product context.

### Added
- Added a complete `README.md` with product introduction, features, operation, API fields, clone/install instructions, file descriptions, privacy notes, and third-party references.
- Added `LICENSE.txt` containing the supplied Climano Proprietary Source-Available License.
- Added `CONTRIBUTING.md` explaining permitted feedback and the license restrictions on code contributions.
- Added `SECURITY.md` documenting permissions, external data flows, user privacy guidance, and vulnerability reporting.
- Added this `CHANGELOG.md`.

### Notes
- Climano is not currently published on the Chrome Web Store. The README uses a `git clone <REPOSITORY_URL>` placeholder until the repository URL is finalized.
- Existing forecast behavior and Open-Meteo request fields are unchanged in this branding/documentation release.
