04 / Data & privacy

Clear weather.
Clear about data.

Climano uses external services to find an approximate location and retrieve weather information. Here is what is sent and where.

01

IP lookup
ipapi.co receives your public IP as part of an approximate location request.

02

Forecast requests
Your selected latitude and longitude are sent to Open-Meteo to return weather data.

03

Place search
The city or place name you enter is sent to Open-Meteo's Geocoding API.

04

Local preferences
Your preferences, last location, and cached forecast are stored with Chrome local storage.

◇TRANSPARENCY NOTE

No first-party analytics.

The current project does not implement its own analytics or application server. Weather and location features still rely on the third-party services described here.

Device geolocation is requested only after you select “Use device location”. Chrome's permission prompt is controlled by the browser.

05 / Get started

A few steps
to your forecast.

Climano is currently distributed as a source project and is not listed on the Chrome Web Store. Load the extension in Chrome using Developer mode.

↗No build step. No weather API key.
The current version can be loaded directly from the project folder.

Climano is proprietary source-available software. Review the included LICENSE.txt for the permitted uses.

01

Clone the repository

Open a terminal in the directory where you keep your projects, then run this command:

git clone https://github.com/darshseraphic/Climano.git
This creates a Climano folder on your computer. Git must be installed.
02

Open Chrome extensions

In Chrome, visit chrome://extensions.

03

Enable Developer mode

Turn on the Developer mode switch, usually shown near the top-right of the extensions page.

04

Load the cloned folder

Click Load unpacked, then select the cloned Climano folder — the folder containing manifest.json.

05

Pin Climano

Open Chrome's Extensions menu and pin Climano for quick access.

06 / Frequently asked

A little more
to know.

Some useful details before you get started.

Where does Climano get its weather data?

Current conditions and forecast values come from the Open-Meteo Forecast API. City and place search uses the Open-Meteo Geocoding API.

How far ahead does the forecast go?

The extension requests three past days and three forecast days (a six-day daily range), using the location's automatic timezone. The exact values displayed depend on the API response for the selected place.

Can I switch between Celsius and Fahrenheit?

Yes. Climano includes a temperature-unit control for switching between Celsius and Fahrenheit.

Can I choose light or dark mode?

Yes. The extension supports System, Light, and Dark themes.

Does Climano need an API key?

No weather API key or build step is required for the current implementation.

Is Climano on the Chrome Web Store?

Not at this time. The current project is loaded through Chrome's Developer mode using the “Load unpacked” option.
