Thank you for taking an interest in Climano. Feedback that helps improve reliability, clarity, accessibility, and user safety is welcome.

## Ways to contribute

- **Report a bug:** describe what happened, what you expected, and the steps needed to reproduce it.
- **Suggest an improvement:** explain the user problem and the proposed behavior without attaching modified project code.
- **Accessibility feedback:** identify keyboard, contrast, labeling, or screen-reader issues.
- **Compatibility feedback:** include your Chrome version, operating system, and whether the issue is reproducible in a clean extension installation.
- **Security report:** do not open a public issue for a suspected vulnerability. Follow [`SECURITY.md`](SECURITY.md).

## What to include in a useful report

1. A concise title and description.
2. Exact reproduction steps.
3. Expected and actual results.
4. Chrome version and operating system.
5. Relevant console errors with personal information removed.
6. Screenshots only when they do not expose precise location or other private information.

## Review and permission

Feedback may be reviewed by the maintainer, but submission does not guarantee acceptance or a response. If you want to propose a code contribution or another use not allowed by the license, request written permission first using the contact details in `LICENSE.txt`.
